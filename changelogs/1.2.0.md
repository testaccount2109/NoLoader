## 📋 Launcher Changelog v1.2.0

### ✨ New Features

#### Play & Launcher Mods
- **Quick Server Join** - Reconnect to the most recently joined multiplayer server shown beneath Play. The server is read from the selected profile's Minecraft game log.
- **Launcher Mod Switches** - Quick Server Join and SkinAPI are listed as built-in launcher mods and can each be turned on or off in Settings → Launcher Mods.
- **NoLoader Splash** - The launcher header now shows the Minecraft-style splash text “with NoLoader”.

#### Skins
- **SkinAPI Browser** - Browse and search community skins from The Skindex without leaving the launcher.
- **Save to Skin Library** - Add a selected community skin to the existing launcher skin library, then equip it from the Skins tab when you choose. Importing a skin does not equip it automatically.

#### Updates
- **Installer-based Updates** - New versions open the matching GitHub release page so you can download and run the installer for your operating system.
- **Per-version Update Prompt** - Dismiss a specific update prompt permanently or close it and see it again on a later launch.
- **One-time Changelog** - The changelog for an installed launcher version is shown once on the first launch after the version changes.
- **Installer-only Release Assets** - Tauri updater signature/archive files are no longer included in published GitHub release downloads.

### 🐧 Linux
- **RPM Package** - Linux x86_64 releases now include AppImage, Debian, and RPM packages.
- **Linux Release Guidance** - README documents supported package formats and the WebKitGTK 4.1 runtime requirement.

### 📚 Documentation
- **Release-ready README** - Download choices, Linux requirements, update steps, build setup, and third-party notices are now collected in one overview.
