# NoLoader 1.0.5

- Add a built-in Play screen button that starts the profile and rejoins the latest server recorded through NoRisk Quick Play.
- Add `api.gameMods.installBundled` for launcher mods to copy a packaged Minecraft JAR into a selected Fabric, Forge, Quilt, or NeoForge profile after a direct button action.
- Validate packaged JAR paths, archive signatures, profile loaders, file size, and collisions; Minecraft loads the JAR on the next game start.
