# NoLoader 1.0.6

- Add per-mod HTTPS update feeds checked at launcher startup, with version comparison and download/changelog links in the mod manager.
- Add `api.updates.check()` for an extension to check its declared feed on demand.
- Add permission-gated `api.network.request()` for bounded HTTPS calls to mod backends.
- Document the full Fabric/Forge/Quilt/NeoForge in-game runtime alongside the launcher mod runtime.
