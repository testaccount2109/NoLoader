# Launcher Performance Controls

This extension demonstrates `launcher.features.manage` and `launcher.performance.read`. Turning off News prevents its panel and requests from mounting; turning off CurseForge hides its source selector and blocks direct CurseForge service calls; turning off Effects disables the animated player renderer and background grid; turning off Ads unmounts the ad component. Disabling this extension removes its overrides and restores default behavior. It requests API 2 because it uses APIs introduced in that version; current NoLoader builds retain support for older API versions.

The performance page reports active extension count and extension API request volume/latency. These are launcher extension metrics, not a claim about whole-process CPU or memory. Build with `yarn sdk:performance-mod:build`, then copy this directory with `dist/index.js` and `noloader.mod.json` into the directory opened by **NoLoader → Open extensions folder**. Refresh NoLoader and enable the extension. Review the feature list before enabling controls because they change launcher behavior.
